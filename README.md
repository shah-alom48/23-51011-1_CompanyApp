# CompanyApp

## Project Description
CompanyApp is a C# Windows Forms application designed to manage employee information and company-related data.

## Features
- User Login and Registration
- Employee Management
- Employee Information Management
- Dashboard
- SQL Server Database Integration

## Technologies Used
- C#
- .NET / Windows Forms
- SQL Server
- Visual Studio

## Project Structure
The project contains the main application files, forms, database connection, and employee management modules.

## How to Run
1. Open the project in Visual Studio.
2. Configure the SQL Server database connection.
3. Build the project.
4. Run the application.
